## ③ 今回追加した未見検証
「未来データを学習に使わない」だけでなく、実戦ゲートをより厳しくしました。

- ベース予測はWalk-forwardで、各レースより前の結果だけでモデル学習
- 購入条件の選定もnested Walk-forwardで、テスト期間を見ずに過去だけで決定
- テスト直前1日を学習側から除外するエンバーゴを追加
- 未見総回収率
- 未見期間の黒字率
- 直近4期間の黒字安定性
- 未見期間回収率の中央値
- 利益が1期間だけに偏っていないか
- 時系列損益の最大ドローダウン

を保存・表示します。

### 実戦ゲート
回収率100%を一度超えただけでは合格にしません。
200件以上の未見評価に加え、複数期間で利益が再現できることを重視します。
