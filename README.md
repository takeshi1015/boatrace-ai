# BOAT RACE AI v2.13.0 — 時系列適応・利益学習強化版

## 目的

v2.12.0までの「当たりやすさの学習」に加え、v2.13.0では **現在の傾向へ追従しながら、利益につながった条件だけを残す** 学習を強化します。

## 主な変更

- 学習履歴を最大220日へ拡張
- Walk-forward未見予測を最大175日まで拡張
- 30日・90日・180日・長期の成績を別々に評価
- 直近30日を最も重視し、90日・180日・長期も使って安定性を確認
- 各期間で候補ルールを作り、複数期間で崩れにくいルールだけを採用
- 小標本の高回収率は100%へ強く縮小して、偶然の大当たりを過大評価しない
- 直近期間でROI 90%未満の条件には追加ペナルティ
- 現在のルールについて期間別「件数・的中率・回収率・損益」を画面表示
- 従来の券種別確率校正、条件別不得意補正、展示データ品質ゲートは維持

## 未見回収率

未見回収率は、AIが学習に使っていない未来側のデータだけで予想を再現し、1購入100円と仮定したときの

`払戻総額 ÷ 購入総額`

です。

- 100% = 損益分岐
- 85.2% = 10,000円購入に対して約8,520円戻る水準
- 110% = 10,000円購入に対して約11,000円戻る水準

ただし過去の未見検証であり、将来の利益を保証するものではありません。

## 時系列適応の考え方

短期間だけ高回収率でも、その結果が数件の高配当に依存している場合は採用しません。
30日を重く評価しつつ、90日・180日・長期でも大崩れしていない条件を優先します。

## 注意

複数券種の過去締切時オッズ履歴はまだ十分に蓄積されていないため、利益学習の中心は既存の3連単未見バックテストです。3連複・2連単・2連複は券種別確率校正と当日実オッズ比較を継続します。
