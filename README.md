# BOAT RACE AI v2.13.1 — 高速化・未見検証復旧版

## 修正目的

v2.13.0では時系列利益学習を強化した一方、起動時の再学習が重くなり、さらに未見評価が0/200になる条件判定不具合がありました。v2.13.1では予測ロジックの考え方を維持しながら、以下を修正しています。

## 主な修正

- 未見評価0/200の原因だった、利益選別バックテスト開始条件を修正
- Walk-forward検証は未来側を厳密に分離したまま、28日ブロックで再学習してモデル再構築回数を削減
- 利益選別の再評価間隔を7日→14日にして重複計算を削減
- 30/90/180日＋長期の利益評価は維持
- ルール探索は30日・90日・全期間で候補を作り、180日は評価に使用する方式へ軽量化
- 通常の「当日データ・オッズ更新」では長期学習キャッシュを消去しない
- 重い再学習は「最新結果で再学習する」を押した時だけ実行
- 長期学習・モデル・未見検証キャッシュを24時間保持

## 運用

### 日中
「当日データ・オッズ更新」を使用します。
当日レースと実オッズは更新されますが、過去データからの長期再学習は走らないため、待ち時間を大幅に短縮します。

### 翌日または結果反映後
「最新結果で再学習する」を1回実行します。
公開済み最新結果を教師データへ取り込み、モデル・確率校正・未見検証・時系列利益条件を更新します。

## 未見検証

未見検証は、各テスト期間より前のデータだけでAIを学習し、その後の未来側レースで予想を再現します。v2.13.1では、この未来側検証を広い期間で維持しながら、モデルの再学習回数を減らして高速化しています。

未見回収率100%未満、黒字期間率不足などの場合は、従来どおり実戦ゲートを未合格にして「見送り」を優先します。
