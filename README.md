# BOAT RACE AI v2.13.3a — ①保存・復元機能

今回は4段階改修の「①保存・復元機能」だけを実装しています。

## 重要
Streamlit Community Cloudでは、アプリ実行中に作成したローカルファイルは
再起動・再デプロイ後まで残ることが保証されません。

そのため、学習完了後に「学習スナップショットZIP」をPCへ保存し、
次回起動時に同じZIPをアップロードして復元する方式にしました。

## 操作
1. 「最新結果で再学習」が正常完了する
2. 「① 学習スナップショットの保存・復元」を開く
3. 「学習スナップショットをPCへ保存」を押す
4. 次回起動時、保存したZIPを選び「この学習結果を復元」を押す

## 今回はまだ変更しない項目
- ②増分学習
- ③未見検証の再設計
- ④追加の高速化

保存・復元が正常に確認できてから順番に実装します。
