# BOAT RACE AI v2.11.2 — 条件別得意不得意学習版

## 追加した学習

- 競艇場別
- 1号艇条件別（1号艇の1着確率帯）
- レース帯別（1-4R / 5-8R / 9-12R）
- 風速帯別
- 波高帯別

これらはすべて Walk-forward の未見予測だけを使い、「AI予測確率に対して実際にどれだけ当たったか」を条件別に学習します。
不得意条件では確率を下げますが、得意条件だからといって確率を上げることはしません。

## オッズ帯・人気帯

BOAT RACE公式では過去レースの締切時オッズページ自体は参照できますが、現行アプリには大量の過去締切時オッズを永続保存した履歴がまだありません。
そのためv2.11.2では、当日の実オッズ順位とオッズ帯に対して保守的なリスク補正を行います。

- 100倍以上: 減点
- 300倍以上: さらに減点
- 人気下位25%: 減点

今後、締切時オッズ履歴が十分蓄積した段階で、この市場補正を「過去実績から学習する補正」へ切り替えられる構造にしています。

## 期待値の流れ

生AI確率
→ 券種別確率校正
→ サンプル不足補正
→ 条件別不得意補正
→ 当日市場リスク補正
→ 安全補正AI確率
→ 実オッズ
→ 安全補正期待値

## 安全方針

- 未見回収率ゲートは維持
- 不得意条件は減点のみ
- 条件別学習で確率を上方修正しない
- 高オッズ・低人気は保守的に減点
