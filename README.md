# BOAT RACE AI v2.11 — 日次自己学習・確率校正・複数券種版

## 追加機能
- 過去120日の公開済み結果を毎回再取得し、日付が進むたびに最新結果を自動で教師データへ追加
- Walk-forwardの未見予測と実結果を使った確率校正（ロジスティック校正＋保守的ブレンド）
- 3連単120通りから、3連複20通り・2連単30通り・2連複15通りのAI確率を数学的に集約
- BOAT RACE公式の3連単・3連複・2連単・2連複オッズを無料取得
- 全券種を横断して「高確率寄り」「高期待値寄り」「優先券種＋買い目」を自動選択
- 締切30分以内は直前オッズ取得
- 校正前後のBrierスコア、最新学習日、学習レース数を画面表示

## 自己学習の考え方
Streamlitのローカルファイルを「AIの記憶」に依存させず、毎回公開アーカイブから過去結果を再構築します。したがって翌日に新しい結果が公開されれば、自動的に学習対象へ入ります。

## 注意
複数券種の過去リアルタイムオッズ履歴はまだ蓄積していないため、未見回収率ゲートは従来の3連単ベースです。複数券種は当日の実オッズ比較を行う「試験候補」として扱います。
