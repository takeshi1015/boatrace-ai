# BOAT RACE AI v2.10.1 — 最終購入判断UI

## 修正内容
- 120通り詳細のAI確率を % 表記へ統一
- 最上段に「買い / 見送り → 推奨2案 → 優先案」を表示
- 高確率寄り / 高期待値寄りを比較して優先案を自動表示
- 締切30分以内は直前オッズを再取得し、2案と優先案を再判定
- 未見200件ゲート未合格時は、優先案は参考表示のみで最終判断は見送り

## 優先案ルール
- 高確率案が AI確率5%以上かつ期待値1.0以上で、EV差が大きくなければ高確率寄り
- 高期待値案のEVが高確率案より50%以上高く、かつ1.5以上なら高期待値寄り
- 高確率案のAI確率が高期待値案の2倍以上なら高確率寄り
- その他は高期待値寄り
