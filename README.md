# BOAT RACE AI v2.9.1 — 購入判断・期待値最適化版

## 主な変更

### 1. 購入候補を画面最上段に大きく表示
各候補について一画面で:
- 買い / 見送り
- 場・R
- 締切までの残り時間
- 買い目
- 実オッズ
- AI確率
- 期待値
- 利益選別スコア
- 120通りオッズ取得数
- 判断理由

### 2. 買い目選定を120通り期待値方式へ変更
AIの1位予想をそのまま購入するのではなく、
120通りすべてについて:

期待値 = AI予測確率 × 実オッズ

を計算。

AI確率0.8%以上の買い目の中から、
期待値が最大の3連単をレースの買い目候補として選択。

### 3. 120通り詳細の実オッズ修正
AI確率表と公式実オッズを race_id + combo 単位で明示的に結合。
comboを文字列へ統一し、詳細画面と最終評価が同一データを使用。

### 4. 実戦投入ゲート維持
未見検証200件以上などのゲートが未合格なら、
期待値が高くても「見送り」。
参考候補としてのみ表示。
