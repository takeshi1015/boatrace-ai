# BOAT RACE AI 無料版 v2.6

実装内容:
1. 結果未確定レースの日付を毎回再取得し、確定したら自動精算
2. 100円/予想で的中率・回収率・累計収支を計算
3. 実オッズ100通り未満のレースだけ、長めタイムアウトで1回再試行
4. 1着・2着・3着を別モデルで学習し、条件付き確率として3連単120通りを構成
5. 会場、R、艇番、進入、級別、年齢、体重、F/L、平均ST、全国/当地勝率、
   モーター/ボート2連率、展示ST、展示タイム、風、波、気温、水温、
   レース内相対値を特徴量化
6. 過去より未来を学習しないウォークフォワード方式でバックテスト
7. 3連単1点の的中率だけでなく、公式払戻を用いた100円購入回収率も表示

注意:
- 過去バックテストの回収率は「モデルの確率1位を各レース100円1点購入」の成績。
- 過去のリアルタイムオッズを保存していないため、期待値フィルター込みの過去回収率ではありません。
- Streamlit無料環境のローカルCSVは永続保証されないため、成績CSVを定期保存してください。
