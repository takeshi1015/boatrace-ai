# BOAT RACE AI v2.13.3d — ④分割・再開可能な高速化

4段階改修の第4段階です。

## 維持
- ① 学習スナップショット保存・復元
- ② 新規結果だけを検知する増分モデル更新
- ③ 1日エンバーゴ付き厳格未見検証

## ④ 今回の高速化
従来の「完全再学習＋未見検証」は、複数回のモデル学習と最終集計を
1回のStreamlit実行で連続処理していたため、長時間化しやすい構成でした。

v2.13.3dでは「完全再学習を1段階進める」方式に変更します。

### 処理段階
1. 直近180日で現在モデルを更新して保存
2. 未見予測 1/4 を作成して保存
3. 未見予測 2/4 を作成して保存
4. 未見予測 3/4 を作成して保存
5. 未見予測 4/4 を作成して保存
6. 厳格未見検証・確率校正・券種校正・実戦ゲートを集計して保存

各クリックでは原則1回の重いモデル学習だけを行います。
処理が終わるたびに途中経過を保存するため、次回は続きから再開できます。

### データ更新時の安全策
途中処理中に公開結果の日付またはレース数が変わった場合は、
異なるデータ世代の未見予測を混ぜないよう途中経過を自動リセットします。

### 学習スナップショット
途中経過もPC保存用スナップショットに含まれます。
Streamlit環境が再起動する可能性がある場合は、段階終了後に保存しておけば復元できます。

## 通常運用
日々の更新では「新規結果だけモデル更新」を使用します。
完全再学習は厳格未見検証を作り直す必要があるときだけ段階的に実行します。
