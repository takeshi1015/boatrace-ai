# BOAT RACE AI v2.13.2 — 保存型学習・未見検証修正版

## 今回の最優先修正

- 通常起動では重い長期再学習を行わない
- 学習済みモデル・確率校正・未見検証を `.runtime_cache` に保存し再利用
- 「当日データ・オッズ更新」は当日情報だけを更新
- 「最新結果で再学習」を押したときだけ220日学習・厳密Walk-forward検証を実行
- v2.13.0/1で `0/200` になった利益選別OOSを、安定していた単一期間ルールの厳密Walk-forwardへ戻して修正
- 未見評価が未実施の場合は `0.0%` と表示せず **「未実施」** と表示
- 時系列適応は「現在の購入ルール」の30/90/180日評価に残し、未来側OOSの評価ロジックとは分離

## 通常運用

1. アプリを開く
2. `当日データ・オッズ更新` で当日情報を更新
3. 「買い」が出た時だけ購入判断を検討
4. 最新結果を学習へ反映したい時だけ `最新結果で再学習` を実行

再学習は重い処理ですが、完了した結果を保存するため、その後の通常起動では同じ計算を繰り返しません。

## 未見回収率

AIがその時点では学習していなかった未来側レースだけを用いた回収率です。
`払戻総額 ÷ 購入総額 × 100` で、100%が損益分岐です。

未見検証が実行されていない場合、本版では0%とは表示せず「未実施」と表示します。
