# BOAT RACE AI v2.13.3e — ⑤赤字条件除外・利益フィルタ

①保存・復元、②増分学習、③厳格未見検証、④分割再学習を維持したまま、
回収率改善のための第5段階を追加します。

## ⑤の考え方
単純に「過去に儲かった条件」を現在に当てると過学習になります。
そのため厳格未見検証の各期間ごとに、

1. そのテスト期間より前のOOS予測だけを使用
2. 場、R帯、1号艇強弱、予測1着艇、AI確率帯、確信度、風、波ごとの回収率を計算
3. サンプル不足を避けるため損益分岐100%へ強く縮小
4. 明確に赤字の条件だけ確率を下げる
5. 特に悪くサンプル十分な条件は購入候補から除外
6. そのルールを未来側のテスト期間へ適用

という順で検証します。

良い条件を過度にブーストする機能は入れていません。
狙いは「当てに行く」より、AIが苦手なレースを買わないことで回収率を改善することです。

## 軽量再評価
画面上部に「⑤利益フィルタ再評価」を追加しました。
これは既存の未見予測を使うため、基礎モデルの34,000件再学習は行いません。
通常、完全再学習よりかなり短時間で⑤の効果を確認できます。

## 実戦ゲート
⑤を追加しても、未見回収率100%超、未見件数、期間黒字率、
中央値回収率、利益偏りなど既存の厳格ゲート条件は緩めません。
