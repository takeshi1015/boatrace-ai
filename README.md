# BOAT RACE AI v2.12.0 — 予測精度・学習能力強化版

## 今回の中心は画面ではなく予測エンジン

### 1. 直近レースを重く学習
- 直近結果ほど学習ウェイトを高くする指数減衰を導入（半減期50日）
- 古いデータも最低25%の重みで残し、短期的な過学習を抑制

### 2. 過去実績の事前分布をモデルへ追加
Walk-forwardでも必ず過去側だけから計算します。
- 会場 × 枠番
- 会場 × 進入コース
- 選手本人
- 会場 × モーター番号
- 級別

サンプルが少ない条件は全体平均へベイズ縮約するため、少数データを過信しません。

### 3. 展示/ST/進入の情報品質ゲート
モデルは欠損値があっても予測できますが、実戦購入候補にするには
- 進入コース
- 展示ST
- 展示タイム
が原則5/6艇以上揃っていることを要求します。
不足時はAI確率も自動縮小し、最終的な「買い」にはしません。

### 4. 特徴量を強化
- 各艇のレース内順位（選手勝率・当地勝率・モーター・ボート・展示・ST）
- 当地成績と全国成績の差
- モーター＋ボート複合力
- 枠と進入のずれ
- 前半/後半レース位置
- 展示データ充足度・気象データ充足度

### 5. 安全側の方針を維持
- 未見Walk-forward検証
- 券種別確率校正
- 条件別不得意補正
- 未見回収率ゲート
- 高オッズ市場リスク補正
はすべて維持しています。

## 注意
v2.12.0は「精度が必ず上がった」と決め打ちする版ではありません。
新モデルも未来データを混ぜない未見検証を通し、回収率・黒字期間率が基準を満たした場合だけ実戦ゲートが開きます。
