# BOAT RACE AI 無料版 v2.5

## 追加機能
- 予想ログの自動記録
- 当日結果の自動取得
- 3連単の的中判定
- 100円/予想基準の払戻・収支・回収率
- 外れ方の自動分類
  - 1着予測外れ
  - 2・3着順違い
  - 2着外れ
  - 3着外れ
  - 相手艇外れ
- 外れ方別の予測確率・期待値・オッズ集計
- 成績CSVダウンロード
- 最新結果で再学習するボタン
- 公開結果は過去60日データへ自動的に入り、再学習時の教師データになる

## 注意
Streamlit Community Cloud のローカルファイル保存は永続保証されません。
無料運用では成績CSVを定期保存してください。
将来はGitHub/Google Sheets等への永続保存を追加できます。
