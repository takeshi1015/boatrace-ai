# BOAT RACE AI v2.8 — 未見データ100%超ゲート

実戦購入候補へ昇格できる条件:
- 条件調整に使っていない未見データ総回収率 > 100%
- 未見選別 200件以上
- 15件以上購入した未見期間の60%以上が回収率100%超
- 直近未見期間でも半数以上が回収率100%超
- 当日の過去条件を通過
- 当日の実オッズ100通り以上取得
- 当日期待値 >= 1.05
- 買い目予測確率 >= 0.8%

ゲート不合格時:
- 参考予想は表示
- 実戦購入候補は0件
- 実戦ログへ新規記録しない

検証方法:
Nested walk-forward。外側の未見期間は、その期間に使う購入条件の最適化に使用しない。

注意:
未見データで100%を超えたとしても将来の利益を保証しません。
100%を無理に作るのではなく、確認できなければ実戦投入を停止する設計です。
