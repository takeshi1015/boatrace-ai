# BOAT RACE AI v2.13.3b — ①保存・復元＋②増分モデル更新

小分け実装の第2段階です。

## ① 保存・復元
学習モデル、厳密検証結果、増分学習状態を「学習スナップショットZIP」としてPCへ保存できます。
次回起動時にZIPをアップロードすると復元できます。

## ② 増分モデル更新
「新規結果だけモデル更新」を追加しました。

- 保存済み状態と公開済み結果のrace_idを比較
- 新しく確定したレースが0件ならモデル再計算を完全に省略
- 新規レースがある場合だけ、直近180日データでモデルを1回だけ再適合
- 34,000件超の全履歴再学習や厳密Walk-forward検証は実行しない
- 新規追加件数、保存済み学習件数、最終結果日、更新日時を保存
- 学習スナップショットにも増分学習状態を含める

モデルが使用している分類器はオンラインpartial_fit方式ではないため、
「増分学習」は新規結果だけを検知し、最近180日の学習窓で1回だけ再適合する
安全なローリング更新方式です。全履歴を毎回再計算する方式ではありません。

## まだ変更しない項目
- ③ 厳密な未見検証の再設計
- ④ 追加高速化

②までの動作確認後に③へ進みます。
