# BOAT RACE AI 無料版 v2.4 — 実オッズ取得最優先

## 変更内容
- BOAT RACE公式3連単オッズを最優先で取得
- `www.boatrace.jp` と `boatrace.jp` の両方を通常アクセスで試行
- 通常アクセス前にBOAT RACEトップページへアクセスし、通常のセッション/クッキーを準備
- Streamlit Cloudから公式ページへ直接取得できない場合だけ、無料Reader経由で同じ公式ページを取得
- HTML表のrowspan展開とMarkdown表の両方を解析
- 取得経路、HTTP status、受信バイト数、テーブル数、復元組合せ数、エラー種別を画面に表示
- 取得できない場合はオッズ・期待値を推測しない

正常時は「取得組合せ数」が最大120になり、「実オッズ」に数値が表示されます。
