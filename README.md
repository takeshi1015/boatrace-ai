# BOAT RACE AI v2.11.1 — 券種別確率校正・過大EV抑制版

## 今回の強化

- 3連単・3連複・2連単・2連複を券種別に未見データで確率検証
- 各券種について「AIの平均予測確率」と「実際の的中率」を比較
- 過去に確率を高く見積もり過ぎていた券種は安全係数で確率を自動縮小
- 未見サンプルが少ない間も不確実性係数でさらに保守的に補正
- 補正後確率 × 実オッズ = 安全補正期待値として再計算
- 券種別未見校正200件未満、過大評価が大きい、校正品質が悪い券種は購入候補から除外
- 従来の未見回収率ゲートも維持。全体ゲートが不合格なら最終判断は見送り
- 購入候補の最低安全補正期待値を 1.05 → 1.10 に引き上げ

## 重要な考え方

v2.11ではEVが3～7と大きく出るケースがありましたが、AI確率そのものが過大ならEVも過大になります。
v2.11.1では、過去の未見レースで「20%予想が実際に何%当たったか」を券種別に照合し、
そのズレとサンプル不足を差し引いた確率だけで期待値を計算します。

## 画面

「券種別の未見確率信頼度」に、各券種の未見サンプル数、平均予測確率、実際の的中率、
安全係数、信頼可 / 試験中を表示します。
