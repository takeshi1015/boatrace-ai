# BOAT RACE AI v2.7 利益選別AI

## 目的
「全レースを予想するAI」から、
「予想の中から買う価値があるレースだけを選ぶAI」へ移行。

## 追加内容
- ベースAIの時系列予測を蓄積
- 第2段の利益選別AIを追加
- 購入条件を過去期間だけで最適化
- 次の未見期間で回収率を検証する二重時系列バックテスト
- サンプル不足・過学習を抑えるため候補ルールを限定
- ROIは100%へ縮小補正して選別条件を評価
- 当日は過去選別条件 + 実オッズ期待値>=1.05で最終購入判定
- 条件を満たさない日は「購入候補なし」とする
- 実戦ログは最終購入候補だけ記録

## 制約
過去のリアルタイムオッズを保存していないため、
過去の利益選別バックテストは予測確率・確信度・確率差・1着艇など
当時取得可能な非オッズ情報で選別しています。
当日の最終判定だけ現在の実オッズ/期待値を使用します。
