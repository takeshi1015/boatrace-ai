# BOAT RACE AI 無料版 v2.3

## 公式3連単オッズ取得を修正

BOAT RACE公式の3連単オッズページは、6つの1着艇ブロックを横に並べ、
各ブロック内を「2着艇・3着艇・オッズ」の3列で表示しています。
2着艇にはHTMLの rowspan が使われるため、単純なテキスト検索では
120通りを取得できません。

v2.3では:
- HTML table の rowspan / colspan を展開
- 6ブロック × 20行 × 3列から120通りを復元
- 公式ページが「データはありません」の場合は推測しない
- ブラウザ相当のHTTPヘッダーを使用
- 実際に何通り取得できたかを画面に表示
- 最大24レース、8並列の高速取得は維持

実オッズ取得成功時は「取得組合せ数」が最大120になります。
